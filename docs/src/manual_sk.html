NetBox ISC DHCP – návod

Plugin pre NetBox 4.7+, ktorý z dát NetBoxu skladá konfiguráciu ISC DHCP servera. Verzia návodu: {{VERSION}}

1. Čo plugin robí

Plugin z objektov NetBoxu (tenanti, prefixy, DNS servery) vytvára súbory pre ISC DHCP server: hlavný dhcpd.conf, tabuľky tried a statických hostov pre skupiny tenantov a súbory subnetov podľa typu poolu. Súbory sa ukladajú hotové (s hashom SHA256) a prepočítajú sa pri zmene dát. DHCP server si ich sťahuje vlastným skriptom.

2. Inštalácia a aktualizácia

sudo bash -c 'source /opt/netbox/venv/bin/activate && pip install --upgrade --force-reinstall --no-deps "git+https://github.com/ArK761/NetBox_ISC-DHCP.git@<COMMIT>" && cd /opt/netbox/netbox && python manage.py migrate netbox_isc_dhcp && systemctl restart netbox netbox-rq'

V configuration.py musí byť plugin zapnutý: PLUGINS = [..., "netbox_isc_dhcp"]. Verzia a commit sa zobrazujú vpravo hore na každej stránke pluginu.

4. Nastavenia pluginu (CFG pluginu)

  • Cesta k dhcpd.conf – adresár na DHCP serveri, napr. /etc/dhcp.
  • Základná cesta súborov – napr. /opt/dhcp; pod ňou sú podadresáre.
  • Podadresáre – napr. TABLE, SUBNET; vznikne cesta /opt/dhcp/TABLE.
  • Predvolený podadresár pre tabuľky a podadresár pre subnety.

Všetko je predvolene prázdne – nastavuje si to používateľ.

5. Základný dhcpd.conf

  • Statická časť – globálne nastavenia DHCP servera (authoritative, lease časy, logovanie, primárny subnet). Musí ju napísať používateľ sám; plugin ju nemení.
  • Dynamická časť – plugin do nej zapisuje výhradne riadky INCLUDE (cesty k súborom tabuliek a subnetov), nikdy časti konfigurácie.
  • Záložka Náhľad ukáže celý výsledný súbor.

6. DNS servery

Tabuľka Názov + IP + Používa sa (zaškrtávacie políčko). Naraz môžu byť v použití najviac 2. Ak nie je zvolený žiadny, plugin zobrazuje upozornenie. Zapnuté DNS sú v kóde poolov dostupné ako {{ dns }}. Všetky DNS servery (aj nezapnuté) sa dajú použiť vo Vlastných premenných.

7. Subnety a pooly

Zdroj subnetov

  1. Zvoľte objekt (napr. IPAM › Prefix) a podadresár pre subnety.
  2. Pridať pole – ľubovoľné pole objektu (štandardné aj custom field).
  3. Kliknite na riadok – rozbalí sa zoznam všetkých hodnôt s vyhľadávaním, tlačidlami Vybrať všetky / Odškrtnúť všetky a prepínačom iba zaškrtnuté / všetko okrem zaškrtnutých. Nič nezaškrtnuté = ľubovoľná (nefiltruje).
  4. Pri poli, ktoré určuje typ poolu (napr. POOL_TYPE), kliknite na ikonu kľúča. Pole s viac ako 100 hodnotami sa nedá zvoliť.

Pod podmienkami je počet vybraných objektov a brána (GW) pre všetky rozsahy: prvá alebo posledná použiteľná IP.

Pooly a ich kód

Každý typ poolu má vlastný kód (šablónu), prepínač Generovať a náhľad na konkrétnom rozsahu. Premenné v kóde:

PremennáVýznam
{{ network }}, {{ netmask }}, {{ prefix }}adresa siete, maska, prefix (napr. 10.0.0.0/24)
{{ gateway }}brána podľa globálneho nastavenia
{{ first_usable }}, {{ last_usable }}prvá / posledná použiteľná adresa (nikdy sieť ani broadcast)
{{ ip(n) }}n>0 od adresy siete, n<0 od broadcastu (−1 = posledná použiteľná)
{{ dns|join(",") }}zapnuté DNS servery
{{ cf.POLE }}, {{ obj }}custom fieldy a samotný objekt

Príklad:

subnet {{ network }} netmask {{ netmask }} {
    USE LEASE_600
    option routers {{ gateway }};
    option subnet-mask {{ netmask }};
    pool {
        range {{ ip(2) }} {{ last_usable }};
    }
}
Ak kód na niektorom rozsahu nesedí (napr. rozsahy pre /24 použité na /28), náhľad ukáže červenú chybu a taký súbor sa nepoužije.

8. Vlastné premenné

Pomenované kúsky konfigurácie ISC. Pri pridaní vyberiete voľbu ISC (lease, DNS, sieť, prístup, PXE, DDNS, vlastný text), napíšete popis a hneď nastavíte hodnotu:

VoľbaHodnotaVloží
default + max lease600default-lease-time 600; max-lease-time 780; (násobok 1,3 – nastaviteľný)
domain-name-serverszaškrtnuté DNS serveryoption domain-name-servers …;
allow / deny duplicatesdenydeny duplicates;

V kóde poolu napíšte .. – pri kurzore sa ukáže zoznam premenných; vyberte šípkami a Enterom. Vloží sa riadok USE <popis>, ktorý sa vo výsledku nahradí skutočnými riadkami. Používaná premenná má zámok – popis sa nedá zmeniť ani zmazať.

9. Hosty a MAC adresy (tenanti)

  • Skupina tenantov = trieda DHCP; meno tenanta = host-name.
  • Každá skupina má súbory (napr. Skupina_Table, Skupina_StaticTable) – dajú sa premenovať, pridávať, zahrnúť / vynechať z configu a priradiť podadresár.
  • Pri súbore zaškrtnete custom fieldy tenanta s MAC adresami (1–3) a pole so statickou IP.
  • Tenant bez MAC sa preskočí; so statickou IP ide do statickej tabuľky (pri viacerých MAC MENO_1, MENO_2…).
  • Súbory sa ukladajú hotové a pri zmene tenanta sa prepočítajú; ikona kruhovej šípky ich prepočíta ručne.
